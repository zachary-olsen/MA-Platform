# Frontend

React + TypeScript (Vite) dashboard for the M&A Platform: the screener, company valuation
pages and the charts. In development, Vite proxies `/api` to the FastAPI backend on port
8000.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check and production build
```

See the [root README](../README.md) for the full setup.
